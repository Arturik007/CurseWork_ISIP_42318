 ИНСТРУКЦИЯ ПО ЗАПУСКУ САЙТА «СКЛАДСКАЯ УЧЁТНАЯ СИСТЕМА» (WMS)


Это веб-приложение на Python (Flask). База данных — SQLite (файл warehouse.db
создаётся автоматически при первом запуске).


1. ЧТО НУЖНО УСТАНОВИТЬ


  • Python 3.10 или новее
    Скачать: https://www.python.org/downloads/

  При установке на Windows обязательно отметьте галочку:
  «Add Python to PATH» (Добавить Python в PATH).

  Проверка в командной строке или PowerShell:

    python --version

  Должна отобразиться версия Python (например, Python 3.12.x).


2. ПЕРЕХОД В ПАПКУ ПРОЕКТА


  Откройте PowerShell или командную строку (cmd) и выполните:

    cd C:123/121/131/1312/123412/421/412/42/14/214

  (Укажите свой путь, если проект лежит в другом месте.)


3. ВИРТУАЛЬНОЕ ОКРУЖЕНИЕ (РЕКОМЕНДУЕТСЯ)


  Создание окружения:

    python -m venv venv

  Активация в PowerShell:

    .\venv\Scripts\Activate.ps1

  Если PowerShell блокирует скрипт, один раз выполните от имени администратора:

    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

  Активация в cmd:

    venv\Scripts\activate.bat

  В начале строки должно появиться (venv).


4. УСТАНОВКА ЗАВИСИМОСТЕЙ


  При активированном venv (или без него, но тогда пакеты ставятся глобально):

    pip install -r requirements.txt

  Устанавливаются: Flask, Flask-SQLAlchemy, Flask-Login, Werkzeug.


5. ЗАПУСК САЙТА


  Из папки проекта выполните:

    python app.py

  При первом запуске программа:
    — создаст файл базы данных warehouse.db;
    — создаст таблицы;
    — добавит демо-пользователей (если их ещё нет).

  В консоли появится сообщение, что сервер запущен. По умолчанию адрес:

    http://127.0.0.1:8080
    http://localhost:8080

  Откройте этот адрес в браузере (Chrome, Firefox, Edge и т.д.).

  Доступ с другого компьютера в локальной сети:

    http://<IP-адрес_этого_ПК>:8080

  (IP можно узнать командой ipconfig в Windows.)

  Остановка сервера: в окне терминала нажмите Ctrl+C.


6. ДРУГОЙ ПОРТ (ПО ЖЕЛАНИЮ)


  В PowerShell перед запуском:

    $env:PORT = "5000"
    python app.py

  В cmd:

    set PORT=5000
    python app.py

  Сайт откроется на http://127.0.0.1:5000


7. ВХОД В СИСТЕМУ (ДЕМО-УЧЁТНЫЕ ЗАПИСИ)


  Логин и пароль совпадают:

    admin   / 1234   — администратор (полный доступ, пользователи, настройки)
    keeper  / 1234  — кладовщик (документы, товары, остатки)
    manager / 1234 — менеджер (просмотр, отчёты)

  Для учебного/демо-проекта пароли можно не менять.


8. СТРУКТУРА ПРОЕКТА (КРАТКО)


  app.py           — главное приложение, маршруты, запуск сервера
  config.py        — настройки (секретный ключ, путь к БД)
  database.py      — подключение SQLAlchemy
  models.py        — модели: пользователи, товары, документы, остатки
  requirements.txt — список Python-пакетов
  templates/       — HTML-шаблоны страниц
  static/          — CSS и JavaScript
  warehouse.db     — база SQLite (появляется после первого запуска)


9. ВОЗМОЖНЫЕ ПРОБЛЕМЫ


  «python не является внутренней или внешней командой»
    → Python не установлен или не добавлен в PATH. Переустановите Python
      с галочкой Add to PATH.

  «No module named 'flask'»
    → Не установлены зависимости. Выполните: pip install -r requirements.txt

  Порт 8080 занят
    → Задайте другой PORT (см. раздел 6) или закройте программу,
      которая использует этот порт.

  Страница не открывается
    → Убедитесь, что python app.py всё ещё работает и в консоли нет ошибок.
    → Проверьте адрес: http://127.0.0.1:8080 (не https).

  Нужен «боевой» режим (не для разработки)
    → В config.py задайте переменную окружения SECRET_KEY со случайной строкой.
    → Запускайте через production WSGI-сервер (например, waitress или gunicorn),
      а не с debug=True — для курсовой/локальной работы достаточно python app.py.
